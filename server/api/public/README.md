# Public API routes

公开 API 提供站点设置、语言、页面、路由解析、新闻、招聘和咨询等能力。语言范围和默认语言取自已发布配置，不能在路由层写死英文或回退未发布草稿。

页面响应投影当前发布区块、媒体和相关配置；新闻等业务使用专用服务及公开状态校验。图片规则随媒体引用保留，公开 URL 与文件服务衔接。

当前公开约定见[接口与数据约定](../../../docs/接口与数据约定.md)，页面与业务区块关系见[页面与区块](../../../docs/页面与区块.md)。文件入口 `/uploads/`、`/_ipx/` 和 `/search/` 不属于本目录的 JSON 内容合同。
