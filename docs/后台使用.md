# 后台使用

本文面向日常维护者。页面和模板的开发细节见[页面与区块](页面与区块.md)，部署与数据库操作分别见[部署与运维](部署与运维.md)、[数据库](数据库.md)。

## 登录与权限

首次使用由初始化命令创建 Root，并在首次登录时修改密码。Root 是受保护账号身份，不是需要分配的角色。普通账号通过启用角色取得操作权限和菜单范围；按钮可见不代表服务端一定允许操作。

菜单隐藏只改变导航，不等于撤销接口权限。授权变更会在后续请求重新判断；禁用、删除或重置密码按账号规则撤销会话。不要共享 Root 作为日常协作账号。

## 网站内容

| 入口 | 用途 |
| --- | --- |
| 网站标识 | Logo、favicon 等站点公共素材 |
| 页头、页脚 | 导航、文案、联系方式及对应页面绑定 |
| 模块管理 | 新闻、招聘、客户咨询的启停和引用检查 |
| 站点语言 | 启用语言和默认语言；仅 Root |
| 区块模板 | 登记渲染组件、模板合同、表单及固定预览样例 |
| 路由与 SEO | 公开路径、索引状态、各语言 SEO；仅 Root |
| 页面维护 | 区块内容、顺序、显示状态及场景开关 |

常规流程是创建或选择页面 → 装配区块 → 填写内容和媒体 → 保存草稿 → 预览 → 发布。需要公开访问时，还要检查路由、SEO、语言和导航各自的发布状态。保存草稿不会自动改变官网。

当前后台内容编辑限制选择未启用语言。停用语言不会删除已有翻译；重新启用前先核对目标语言的内容完整性。

站点语言、路由与 SEO、公共模块和页面正文有独立生命周期。发布或恢复一个对象，不等于发布其他对象。页面正文恢复也不会把路径、页头或页脚恢复成旧值。

## 预览与发布历史

页面可查看已保存草稿、已发布版本、单个已保存区块和历史版本。未保存的编辑不会自动进入这些预览。模板库使用已保存固定样例；预览组件使用当前部署代码，不是历史代码截图。

新闻预览将文章放入已发布的新闻详情布局。模板和页面预览中的业务内容使用适配的样例，不以真实提交咨询表单等方式演示。

历史版本恢复会进行当前规则校验，保留工作草稿。非当前发布记录可以在有权限时永久清理；当前版本不能清理。清理历史不会自动删除图片，图片仍可能被草稿、其他历史或模板引用。

## 业务管理

- 新闻：维护文章、分类及展示设置；文章草稿与公开发布分离，页面中的新闻模板读取业务接口。
- 招聘：维护岗位及公开设置；公开岗位不等同于静态正文列表。
- 客户咨询：查看官网提交、分配处理人、修改处理状态和追踪历史。邮件投递需要运维另外配置 SMTP。

模块停用控制公开能力，不删除历史记录。具备相应权限的管理者仍可维护数据和处理历史咨询。模块启用不自动创建或发布页面路由。

## 媒体库

上传后选择媒体记录，不手填本地文件路径。当前支持的文件类型、大小和尺寸以媒体上传校验及界面提示为准。图片可按模板规则调整桌面／手机取景。

删除前先查看引用位置。草稿、当前发布、历史发布、模板封面和相关配置都可能阻止删除；不能只因当前网页没显示就认定无用。若需要释放历史引用，先清理对应的非当前历史版本。

删除是带恢复协调的硬删除，不提供回收站。数据库删除与文件暂存由服务端处理，不能在文件管理器中绕过媒体库删除正式素材。详细文件边界见[部署与运维](部署与运维.md)。

## 系统管理

| 功能 | 维护要点 |
| --- | --- |
| 账号 | 创建、启停、资料、角色和密码重置；保留受保护账号约束 |
| 角色 | 操作权限与菜单范围联合授权，受操作者权限上限限制 |
| 菜单 | 系统导航及官网页面维护入口；显示与授权分开处理 |
| 系统参数 | 修改已登记策略，不通过参数写入数据库凭据或任意执行逻辑 |
| 数据字典 | 维护已登记业务字典和条目，检查引用与启用状态 |
| 定时任务 | 配置周期、启停、手动执行和查看实际执行结果 |
| 系统环境 | 查看当前应用与运行环境信息 |
| 日志 | 按权限查询登录、安全、操作及变更明细，必要时导出 |

任务“已受理”只表示排队成功，不表示执行成功。暂停周期调度不会停止已运行任务；停止等待安全边界，强制终止针对对应 Worker，不结束网站主进程。生产模式且调度器在线才允许执行；开发模式不能用手动按钮代替生产任务验证。

## 列表与失败处理

关键词由“查询”或 Enter 提交，状态和分页使用已经生效的查询条件。后台时间按北京时间显示，日期筛选也按北京时间日历边界解释。

离开未保存表单前确认；保存失败保留草稿。出现版本冲突时刷新并核对他人修改，不反复强行提交旧版本。若提示已保存但刷新失败，先刷新确认，不重放写入。

排错时保留请求编号、操作时间和对象名称，在日志或平台诊断中关联查询。不要把密码、Cookie、完整请求或数据库连接发到公共渠道。
