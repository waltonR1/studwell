# 官网样式与素材

页面、模板和数据规则见[页面与区块](页面与区块.md)。本篇负责展示、动画及文件存放，不重新定义业务合同。

## 样式入口

官网全局入口为 `app/assets/public/css/runtime/themes/studwell/main.css`，字体与排版在同目录 `typography.css`，颜色及布局变量在 `tokens.css`。运行外壳和基础样式位于 `css/runtime`，区块专属样式随所属组件或模块维护。

后台样式由后台布局独立加载，不为修改后台按钮而改变官网全局主题。官网复用语义字号、颜色、容器和控件样式，不重新创建按组件编号命名的全局变量。

字体使用系统字体栈，不要求外部字体下载。维护字号、行高和断点时以当前 typography 源码为准；Logo 图片内的文字不受 CSS 字体规则影响。中英及其他长语言分别检查换行，不用裁掉内容换取固定一屏。

## 桌面与手机展示

区块及外壳入口按 `usePublicViewport` 选择 Desktop／Mobile 展示，通用组件继续共用；不是每个小组件都必须复制两份。稳定入口持有需要跨断点保留的表单或搜索状态。

手机上限为 767px。SSR 与入口水合首帧使用一致结构，入口挂载后再按视口切换，避免异步区块在水合前提前使用手机树。切换时卸载旧展示，动画、监听器和资源要一并释放。

组件专用逻辑放对应 composable 或模块，不按旧 `*.shared.ts` 命名说明机械新建文件。页面自身的挂载和异步加载顺序以当前稳定入口为准。

## 动画与场景

GSAP／ScrollTrigger 等动画在组件生命周期内建立和清理。重建、路由切换及断点变化不能累积事件监听器、滚动锁或旧时间线。

首页遮罩、光标和外壳属于运行模板，可按站点需要修改。场景切换受页面开关控制，长内容应能滚动；矮屏和手机检查实际回退，不通过固定高度或 overflow 裁切按钮和正文。

## 图片规则与取景

模板字段或媒体槽声明完整 `imagePreset`，后台根据合同开放取景、缩放、效果及手机独立调整能力，不靠模板名推断。规则随模板修订保存，引用中的 presentation 随正文草稿及发布快照保存。

```ts
image: {
  mediaId: '媒体实体编号',
  presentation: {
    desktop: {x: 50, y: 50, zoom: 1}
  }
}
```

坐标为 0–100 的百分比，缩放围绕相同位置。允许时才保存手机独立取景及亮度／不透明度；服务端按预设检查范围。公开投影保留这些设置，不只返回媒体 src。

调整弹窗维护独立副本，应用后写回表单，取消不覆盖；最后仍需保存表单和发布。取景不修改原图。`SiteImage` 等通用展示组件负责应用对应规则，不能在每个模板中各写一套相互冲突的裁切逻辑。

## public 和测试资源

| 位置 | 用途和生命周期 |
| --- | --- |
| `public/admin/brand` | 后台品牌，配置入口 `app/config/admin/brand.ts` |
| `public/section-samples` | 数据库模板固定预览样例引用的媒体，随源码和构建交付 |
| `public/uploads` 或配置根目录下的 uploads | 运行媒体，独立持久化、备份和迁移，不进入构建副本 |
| `public/favicon.ico`、`public/robots.txt` | 默认静态入口；站点实际标识还需检查已发布配置 |
| `tests/fixtures/media` | 仅用于测试的原始素材，不公开部署 |
| `public/examples` | 本站自制流程图、取景图和四秒 MP4，用于真实媒体库示例 |

固定模板样例虽然不出现在正式页面，仍可能被后台引用，不能按文件名或“非线上图片”直接删除。

清理前同时核对源码、模板预览样例、草稿、发布及历史和测试夹具。运行媒体先经过媒体库引用检查；人工文件删除不能代替后台媒体删除。

## 修改后检查

检查桌面、手机、长文本语言、加载失败、图片取景和清理行为。涉及文件存放时同时验证原图、IPX 缩放及构建后新上传；涉及模板字段时按页面和发布流程检查。
