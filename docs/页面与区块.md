# 页面与区块

## 内容模型

页面由已登记模板的区块实例装配。模板声明字段、媒体槽、编辑表单、适用范围、公开渲染器和预览渲染器；区块保存自身内容、顺序、可见性及锚点。页面发布保存内容快照，公开读取不临时拼入最新草稿或模板修订。

主要维护数据位于 `website_resources`、`website_drafts`、`website_sections`、`website_templates`、`website_template_revisions`、`website_releases`。媒体、菜单、语言、路由和 SEO 分别维护数据及生命周期。

模板适用范围、字段完整性和模块依赖参与发布校验，页面至少保留一个可见区块；模板不限制实例数量。

默认模板合同见 `scripts/database/seed/data/templates.json`。数据库保存已登记模板及修订，运行期不是每次读取代码预设覆盖后台定义。

## 页面创建与公开入口

1. 在菜单管理中创建官网页面维护入口，并配置需要的角色菜单范围。
2. 在页面维护中添加区块、填写启用语言内容、设置显示状态和顺序。
3. 保存并预览草稿，发布页面正文。
4. 在路由与 SEO 中维护公开路径和各语言 SEO，单独发布。
5. 按需要在页头、页脚配置导航并发布。

页面编码和维护名称来自数据库，不通过新建一个固定 Vue 路由文件登记每个普通页面。`app/pages` 负责通用入口，新闻详情和搜索保留各自的业务接线。

路径、页面维护入口和导航链接属于不同职责。页面可以有内容但尚无公开路径，也可以未出现在导航中；界面显示状态不能代替公开路由或权限判断。

## 普通区块和业务区块

正文、图文、时间轴、同组页面导航、本页侧栏等都按普通区块处理。侧栏占据自己的位置，由模板组织视觉布局，不强制置顶、限制单例或改写其他区块的渲染机制。

新闻、招聘和咨询模块具有专用 API。区块负责展示与交互，模块负责文章、岗位和咨询记录等业务状态。业务开关在模块管理中维护；发布检查会核对相应依赖，不能把业务区块当作一段静态样例文字替代后台数据。

## 场景与默认外壳

页面设置中的场景开关决定是否采用场景切换。前台按页面配置处理区块容器。长内容、表单和媒体仍需检查场景内滚动、焦点及交互；小视口或高度不足时按运行机制回退普通滚动。

默认页头、页脚、品牌 Logo 和首页遮罩属于可替换的运行模板。可以改样式，也可以按站点需要删掉展示示例，但须保留仍需要的导航、语言、SEO 和加载行为。首页遮罩的开关与路由作用范围由运行接线管理，不能在每个页面进入时无条件触发。

搜索是站点运行功能，不是需要在每页装配的全文搜索区块。同组导航和侧栏组件不内置额外搜索表单。

## 新增或修改模板

1. 在 `app/components/public/sections` 新增公开展示组件；需要双端结构时采用现有 Desktop／Mobile 组织方式。
2. 定义字段合同、媒体规则、编辑布局及固定预览样例。字段使用稳定语义，不借模板名称猜图片能力或业务类型。
3. 在渲染器登记中加入组件；构建清单由 `scripts/build-section-renderer-inventory.ts` 生成，组件必须先被构建识别才能在后台引用。
4. 在后台区块模板中登记或修订定义，并配置公开及预览渲染器。需要作为新库默认模板时，同时更新初始化资料。
5. 检查旧实例升级、草稿保存、发布、历史恢复和预览。模板升级使用明确修订流程，不从最新定义静默改写已发布快照。

字段由 `shared/types/website/section-template.ts` 和相应 Schema 描述；表单等管理元数据位于后台合同。公开组件使用 `usePublishedSection` 等发布内容能力，不直接请求后台编辑接口。

媒体字段保存实体引用，服务端投影公开 URL 和展示规则。上传地址、业务 ID、路由链接和编辑器内部稳定键各有不同含义，不能混用。

## 语言与 SEO

系统可用语言登记在 `shared/config/site-languages.ts`，固定 UI 文案位于 `i18n/locales`。后台发布的启用集合和默认语言决定本站公开范围；默认语言必须已启用，停用语言公开访问返回 404。

语言配置与路由／SEO 分别保存草稿、发布指针和历史。发布及恢复时检查另一模块当前线上状态，不把未发布草稿拼成一个混合版本。不跨语言回退正文，不因停用而删除翻译数据。

新增系统语言需补目录、UI 翻译并重新构建，补齐内容和 SEO 后再发布启用；不是仅在数据库增加一个字符串。后台当前不允许选择未启用语言编辑。

## 预览和历史

页面顶部可查看发布内容，装配区可查看已保存草稿或单区块。模板库使用 seed/data/template-samples.json 声明的独立固定样例，初始化只补缺失样例，后台已有值保留。预览不包含尚未保存的输入，历史预览使用当前组件代码。

新闻文章预览使用已发布详情布局，业务样例由预览适配器提供，不提交真实咨询。页面正文预览不附加全站页头页脚；它也不声称完整还原历史站点外壳。

恢复发布版本保留当前工作草稿，重新执行当前合法性检查。清理非当前发布历史会解除该版本的媒体引用，不删除文件或其他版本。当前版本不能清理。

## 搜索字段

搜索从已发布快照按字段合同提取内容：text 默认参与，group／list／tree 递归处理；`searchable: false` 排除自身及子树。媒体、数字、链接、布尔值和未知字段不通过遍历任意 JSON 自动进入索引。

修改搜索声明属于模板合同修订，须随页面发布生效，不能用最新模板覆盖旧快照。新闻使用专用来源适配；岗位与咨询不作为独立搜索结果收录。搜索生成、任务和缓存操作见[部署与运维](部署与运维.md)。

全部页面采用正常数据库内容、Section 装配和发布服务；没有指南专用路由分支。本站内容位于 `scripts/database/seed/data/site.json`，由 `seed/site.ts` 校验，当前站点和初始化使用相同声明。13 个模板均有真实实例及预览样例。首页两个行动链接复用普通同组页面导航模板。

语言数量不是框架上限。已登记语言在后台启停；系统语言目录和 UI 翻译位于 `shared/config/site-languages.ts` 与 `i18n/locales`，新增语言还需补齐正文和 SEO，再构建部署。

示例表单会真实保存咨询；SMTP 仍需配置并独立验证。后台权限、任务和审计从对应后台入口操作，公开页面提供步骤和检查结果，不模拟后台成功。
