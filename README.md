# Studwell

**以区块组织内容，用一套完整的前后台搭建网站。**

Studwell 是一个基于 Nuxt 的个人网站开发项目，适合企业官网、品牌展示站和产品介绍站。它把页面展示、内容管理和常用业务模块放在同一个工程中，让开发者专注于页面设计，也让内容维护可以在后台完成。

仓库内置的 Studwell 指南站同时是使用说明和功能演示：指南、导航、新闻、岗位和咨询表单，都使用项目本身的模板、数据库和发布流程实现。可以从这些示例开始，替换品牌、编写自己的区块，搭建另一个独立网站。

## 能做什么

- **区块搭建页面**：通过模板定义字段和编辑表单，在后台添加区块、调整顺序、控制显示状态；支持正文、图文、列表、侧栏及场景切换等展示方式。
- **管理内容与发布**：保存草稿、预览页面、发布内容、查看和恢复发布历史；页面、页头页脚、语言和路由／SEO 分别维护。
- **维护多语言网站**：内置中文、英语、法语、西班牙语和葡萄牙语示例，可在后台控制启用范围；新增系统语言通过代码扩展。
- **接入常用业务**：提供新闻、招聘和咨询模块，包含各自的管理接口和公开展示；咨询支持处理流程及可配置的邮件通知。
- **管理素材与搜索**：上传图片和视频、设置图片取景、检查媒体引用，并为已发布内容生成站内搜索索引。
- **协作维护后台**：提供账号、角色、菜单和操作权限，以及系统参数、任务调度和审计日志。

## 开发方式

Studwell 将可复用的运行逻辑与站点展示分开组织。页面、模板、导航和内容由数据库维护；展示组件、主题、页头页脚和首页遮罩可以按项目修改。

模板决定“内容如何编辑和展示”，区块实例保存“这个页面具体写什么”。开发新样式时添加 Vue 组件和模板定义，日常更新则在后台完成。

当前以完整源码项目的方式复用，各站使用独立数据库、内容与部署配置。

## 本地开始

### 1. 准备环境

- Node.js `>=24.22.1 <25`
- MySQL 8.4
- 一个使用 `utf8mb4`／`utf8mb4_0900_ai_ci` 的独立数据库，以及具有对应权限的账号

### 2. 安装并配置

在项目目录执行：

```powershell
Copy-Item .env.example .env
npm ci
```

在 `.env` 中填写数据库连接，并确认后台访问地址与 `NUXT_ADMIN_ORIGIN` 一致。全部配置说明见[环境变量样例](.env.example)。

### 3. 初始化系统和本站

```sh
npm run db:init
npm run db:site
npm run db:check
```

- `db:init`：建立表结构，初始化系统数据与 Root 账号。
- `db:site`：安装本站配置、模板、指南页面和业务示例。
- `db:check`：检查迁移、表结构及数据基线。

写入前需要输入实际库名确认。Root 密码在初始化时交互设置，首次登录后需要修改。

如需演示后台账号、角色、字典和咨询记录，可额外运行 `npm run db:samples`。详细分层、预览选项及已有库升级见[数据库文档](docs/数据库.md)。

### 4. 启动开发服务

```sh
npm run dev
```

- [指南首页](http://127.0.0.1:3100/zh/)
- [内容管理后台](http://127.0.0.1:3100/admin/login)

可以先浏览功能演示，再进入后台编辑一个区块，体验从草稿、预览到发布的完整流程。指南中的咨询表单会真实保存记录；邮件发送需要配置 SMTP。

## 项目结构

```text
app/        页面、组件、主题和后台界面
server/     API、业务服务、数据库与任务执行
shared/     前后台共用的类型、校验和规则
scripts/    构建、初始化、迁移和维护工具
drizzle/    数据库结构迁移与快照
public/     品牌及站点静态素材
i18n/       固定界面翻译
tests/      单元、数据库与生产模式测试
docs/       开发、使用与部署文档
```

## 构建与部署

```sh
npm run build
npm start
```

生产运行需要注入环境变量，并配置数据库、持久化媒体目录、搜索目录和任务 Worker。完整步骤见[部署与运维](docs/部署与运维.md)。
